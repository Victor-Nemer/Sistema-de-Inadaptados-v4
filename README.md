# Task Manager – OOP Practice

A small Python project from the Inadaptados academy, built to practice **Object-Oriented Programming**.

## What it does
- Refactors a procedural task program into a class (`Tarea`) that keeps its own data and behavior.
- `sistema_tareas.py` adds a `GestorDeTareas` class that stores tasks, lists them, marks them complete and counts pending ones.

## Files
| File | Description |
|---|---|
| `programa_tareas.py` | Refactor exercise: task as a class with `completar()` and `mostrar()` |
| `tarea_poo.py` | Same exercise, final version |
| `sistema_tareas.py` | `Tarea` + `GestorDeTareas` with an encapsulated task list |

## OOP concepts practiced
Classes and objects · constructors · encapsulation · methods that act on their own state

## Run it
```bash
python sistema_tareas.py
```
Example output:
```
Enviar el reporte semanal a Contabilidad - completada
Pagar a los proveedores del comedor - pendiente
Pendientes: 1
```
